# GitHub Practice Playground

A safe place to try things on GitHub. Nothing here matters, so you can't break anything. Experiment freely!

## Practice exercises

Work through these in order. Each one can be done entirely on github.com.

### 1. Edit a file
1. Open [`practice/scratchpad.md`](practice/scratchpad.md) and click the ✏️ pencil icon.
2. Add a line, for example today's date and something you learned.
3. Click **Commit changes**. You just made a *commit*: a saved snapshot of your change.

### 2. Create a new file
1. Go to the `practice/` folder and click **Add file → Create new file**.
2. Name it something like `hello.md`, write anything, and commit it.

### 3. Make a branch
A *branch* is a separate copy where you can make changes without touching the main version.
1. Click the branch dropdown (top left of the file list), type a name like `my-first-branch`, and click **Create branch**.
2. Edit a file on that branch and commit.

### 4. Open a pull request
A *pull request* asks to bring changes from one branch into another.
1. After committing to your branch, click the **Compare & pull request** button.
2. Write a short title and click **Create pull request**.

### 5. Merge it
1. On your pull request, click **Merge pull request**, then **Confirm merge**.
2. Your change is now in the main branch. You can delete the branch afterwards.

### 6. Open an issue
*Issues* are to-do items or notes about a project.
1. Click the **Issues** tab, then **New issue**, write a title, and submit.
2. Close it when you're done.
