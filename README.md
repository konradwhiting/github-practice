# Project Status Reports

A place to write and keep project status reports, one file per report.

## How this repo is organized

| Folder | What goes in it |
| --- | --- |
| `templates/` | The blank status report template. Copy it to start a new report. |
| `reports/` | Finished reports, named by date: `YYYY-MM-DD-project-name.md`. |

## Writing a new report (on github.com)

1. Open `templates/status-report-template.md` and copy its contents.
2. Go to the `reports/` folder and click **Add file → Create new file**.
3. Name it with today's date and the project, e.g. `2026-09-30-website-redesign.md`.
4. Paste the template, fill it in, and click **Commit changes**.

Reports are written in [Markdown](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax), which GitHub displays as formatted text.
